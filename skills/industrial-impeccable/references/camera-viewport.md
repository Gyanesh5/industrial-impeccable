# A 族 · 相机流视口（自建范式）

> 全调研无现成 skill 覆盖本族（2026-11 确认的空白）。本文件为自建范式初版，底本：海康 VM 四区范式 + ISA-101 暗屏原则。

## 规则

1. **四区结构**：相机画面占主区（深底）；参数/状态列右缘（chrome 浅灰）；工具栏顶部；报警横幅常驻底缘。
2. **overlay 与帧同步**：overlay（ROI 框、检测线、数值贴标）必须与渲染帧同步绘制，禁止 overlay 与图像来自不同时刻的数据。
3. **断流占位**：流断开显示显式 STALE 占位（`state-stale` 色 + "信号中断 HH:MM:SS"），保留最后一帧作背景但打斜纹；禁止静默冻结。断流时长从最后一帧到达时刻起算。
   - **触发式任务豁免**：软触发/Modbus/开关量触发的任务帧不是连续流，"距最后帧超时"的信号中断判定对其豁免（等待触发是常态）；**连接中断（WS 断开）不豁免**——连接问题与触发方式无关。
   - 首帧未到显示"等待画面"占位，不判断流（从未有过画面 ≠ 有过画面后断了）。
4. **多相机宫格**：一屏可比（同尺寸宫格、同位参数）；点击放大单路，Esc 回宫格；宫格内每路带独立 STALE 态。
5. **抓帧对比**：对比视图左右并置（基准帧/当前帧），差异区域高亮且可用列表跳转；不用时间轴翻页找差异。
6. **overlay 样式**：线宽 1–2px、双编码（色+线型：实线=检出/虚线=参考）；文字贴标带底衬避免压图不可读。

## 验收

断流 3s 内出现 STALE 占位；宫格任意一路断流不影响其余路渲染；overlay 数值与图像帧号一致。

## 出处

海康 VM 界面范式（本地案例库）；ISA-101 数据源故障可见（timhok/hmi-design）。
