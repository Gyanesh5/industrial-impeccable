# 设计系统规则（design-rules）

> 本文件是规则层；项目实例（含具体色值与刻度取值）由 templates/design.md 生成到各项目根目录的 DESIGN.md。规则覆盖项目实例，项目实例覆盖默认值。

## 1. 界面模式（先定模式再动手）

每块屏先归入 impeccable 四模式之一（persuade 说服 / operate 操作 / read 阅读 / experience 体验）：

| 本域表面 | 模式 |
|---|---|
| 操作员监控屏、报警、标注画布、配方编辑、换产向导、3D 单元视图 | operate（操作） |
| 数据报表、良率回顾、文档 | read（阅读） |
| 产品官网、宣传页 | persuade（说服） |

操作与阅读模式的雄心表现为精确与克制；品牌活在精确的细节里。产线屏禁用表达欲增强类命令（bolder / delight / overdrive）。

## 2. 语义色表（≤8，报警专用）

以下语义色全站一致、只做其语义、不得挪用，且**不进入分类色板**：

| 语义 | 值 | 用途 |
|---|---|---|
| alarm-critical | `#B3261E` 红 | 设备报警/急停/安全临界。**唯一允许闪烁的语义**（未确认态） |
| alarm-warning | `#C08A00` 琥珀 | 过程警告/降级 |
| state-ok | `#2E6B46` 绿 | 运行正常/在位 |
| state-stale | `#6B5518` 灰褐 | 数据断流/过期。**断流必须显示 STALE 态，禁止显示冻结的"正常值"** |
| state-running | `#2F66D0` | 自动运行中（与 accent 同值，仅限状态灯） |
| state-manual | `#8C5A00` | 手动模式 |
| action-primary | `#2F66D0` | 主按钮 |
| ng-mark | `#B3261E` | NG 标记（与 alarm-critical 同值——NG 即报警级） |

**双编码强制**：任何以颜色区分的状态必须加第二编码（形状 ▲▼/＋−、图标、文字）。红绿盲与灰度打印下不得丢失信息。

## 3. 动效（零装饰）

- 只允许"回答人的动作"的动效：展开指示、确认发生了变化、悬停反馈（色/面变化，≤几像素位移）
- 禁：循环动画（animate-pulse 类）、入场编排（卡片依次飞入）、hover:scale、transition: all
- `transition` 必须点名属性（transition-colors / transition-opacity / transition-transform）
- 所有动效带 `prefers-reduced-motion` 回退

## 4. 文字预算（少即多）

需要阅读文字才能会用 = 界面没设计好。界面文字只保留三类：**状态语义**（标签、徽章）、**空态一句话引导**（一句价值说明 + 创建按钮）、**危险警示**。其余传达手段：占位符显示默认值、悬停提示（title）、交互反馈本身。

- 页头副标题（实现说明类，如"行内开关即时启停 · 编辑保存即生效"）删除——页面身份由导航页签表达；
- 表单 hint 三档分流：默认值解释（"空 = 默认 1"）→ 改输入框占位符；长解释 → 删除（确需保留收进字段悬停）；防呆语义 → 精简保留（"类型不可改，删除重建"）；
- 操作教学文字删除——工具按钮悬停 + 交互反馈本身已覆盖操作方式；
- 空态引导句保留（一句话 + 按钮，属引导不属装饰）；
- 确认对话框、意图清单、告警、错误信息、表单标签、按钮文字不动。

判例来源：vision-monitor 全站清理实测（净删约 60 处，三档分流后表单可读性显著提升）。

## 5. 五项裁决（已定案，不再讨论）

1. **黑底分区不分家**：视口/图表深底，参数/报警 chrome 浅灰（即 §2）
2. **NG/报警色专用**：红黄不入分类板；NG/OK 双编码（即 §3）
3. **动效零装饰**（即 §5）
4. **图表轴分家**：报表（read）用 tufte 风格（范围轴+直接标注，ECharts `registerTheme('tufte')`）；操作员趋势（operate）用**固定量程+阈值线**——操作员要的是"越没越线"
5. **收敛**：操作员屏全站一致（同数据同位、位置记忆）；防收敛机制只用于说服类表面

## 6. 操作模式细则（世界观四样贡献 + 反戏服）

工业主题素材（车间、仪表、示教器）对操作屏只能贡献四样：**字体、色板、密度、一个签名动作**。布局、导航、控件一律平台标准件（ElementPlus）。

禁判例（戏服）：示教器皮肤、物理按钮拟物、仪表边框装饰、功能键栏仿制。

签名动作候选（每产品选一，全站一致）：腔位状态网格、节拍时间轴、相机取景框状态。

## 7. 验收标准（分族硬指标）

| 族 | 硬指标 |
|---|---|
| B 画布 | 缩放对准光标；平移缩放 60fps；吸附可开关；卸载撤销栈 ≥100 步 |
| C 3D | 源/渲染坐标分离+可逆变换记录；Z-up 显式转换；卸载后无泄漏上升趋势 |
| D 监控 | 报警摘要任意屏 1 击可达；过程数值刷新不快于 1s（机器状态例外）；断流显示 STALE |
| E 报警 | 未确认闪烁/已确认常亮；报警条 1s 调出；色+形双编码 |
| F 表格 | 空/加载/错误三态齐；数值右对齐等宽；首列 sticky；过滤进 URL |
| G 向导 | 每步意图清单+可撤销；错误可原地重试 |
| H 报表 | tufte 主题；直接标注无图例框；无双 Y 轴 |
| A 视口 | 断流 STALE 占位；overlay 与帧同步；多相机宫格一屏可比 |
