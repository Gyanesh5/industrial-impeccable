## 2. 双令牌（黑底分区裁决）

屏幕分两个区，各用一套令牌，边界清晰：

### 2.1 视口/图表区（viewport）——深底

图像、画布、图表的领地。深底保证 overlay 与数据序列对比最佳。

```
--vp-bg:        #0F1923   /* 图表底 */
--vp-bg-page:   #0A1119   /* 页底（仅全屏视口页） */
--vp-grid:      #1A2A3A
--vp-border:    #1E3040
--vp-text:      #E8EDF2   /* 主文字 */
--vp-text-dim:  #8899AA
```

分类色（数据序列专用，≤10）：`#5E9CF3 #4DD9C1 #FF6B7A #B388FF #FFC048 #40C4FF #8E99A4 #FF8A65 #69F0AE #FF80AB`

### 2.2 参数/报警 chrome 区——浅灰底

表单、参数、报警列表、导航的领地。浅底适配长时间阅读与纸质化记录。

```
--chrome-bg:      #F4F5F3
--chrome-surface: #FFFFFF
--chrome-border:  #D9D7D1
--chrome-text:    #2B2E33
--chrome-text-dim:#75787D
--chrome-accent:  #2F66D0   /* 唯一 accent：主操作/选中/当前项 */
```

两区不得混用对方底色；同一屏内分界明确（工具栏/边框分隔）。

## 3. 语义色表（≤8，报警专用）

以下语义色全站一致、只做其语义、不得挪用，且**不进入分类色板**：

| 语义 | 值 | 用途 |
|---|---|---|
| alarm-critical | `#B3261E` 红 | 设备报警/急停/安全临界。**唯一允许闪烁的语义**（未确认态） |
| alarm-warning | `#C08A00` 琥珀 | 过程警告/降级 |
| state-ok | `#2E6B46` 绿 | 运行正常/在位 |
| state-stale | `#6B5518` 灰褐 | 数据断流/过期。**断流必须显示 STALE 态，禁止显示冻结的"正常值"** |
| state-running | `#2F66D0` | 自动运行中（与 accent 同值，仅限状态灯） |
| state-manual | `#8C5A00` | 手动模式 |
| action-primary | `#2F66D0` | 主按钮 |
| ng-mark | `#B3261E` | NG 标记（与 alarm-critical 同值——NG 即报警级） |

**双编码强制**：任何以颜色区分的状态必须加第二编码（形状 ▲▼/＋−、图标、文字）。红绿盲与灰度打印下不得丢失信息。

## 4. 刻度与排版

- 间距：8px 基网格；刻度 `8/16/24/32/48`
- 密度两档：总貌档（疏，卡片间距 48px 级）与详情档（密，行高 32–36px、间距 8px 级）——按表面选档，不混用
- 字体：一个 UI 无衬线族；数值用**等宽数字**（tabular figures，`font-variant-numeric: tabular-nums`）
- 字号：正文 ≥15px；标签 12–13px；数字大屏显示按内容自适应
- 禁全大写标签；禁字距加宽（tracking）的小标签
- 单位紧跟数值（`3.2s`、`98.6%`）；表头带单位（`节拍 (s)`），格内不重复
